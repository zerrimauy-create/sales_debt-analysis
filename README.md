# sales_debt-analysis
# Анализ продаж и долговой нагрузки продуктового магазина

## Описание
Проект выполнен на основе данных кассовой системы **Frontol** за 2024–2025 годы. Цель — очистить выручку от крупных чеков (≥ 10 000 ₽) и проанализировать сезонность и динамику продаж.

## Что сделано
- Из сырых данных выделены только продажи (код 11).
- Исключены чеки на сумму 10 000 ₽ и выше, чтобы убрать случайные искажения.
- Посчитана выручка по месяцам для 2024 и 2025 годов отдельно.
- Построена гистограмма для наглядного сравнения.

## Результаты
![Диаграмма сравнения выручки](images/diagram.png)

Диаграмма показывает:
- Пиковые месяцы (высокая выручка) и слабые месяцы (низкая выручка).
- Динамику между 2024 и 2025 годами.
- Точки для планирования закупок и акций.

## Ценность для бизнеса
- Прогнозирование сезонности.
- Сравнение эффективности двух лет.
- Основа для управленческих решений.
